# Outrazo hero spacing refinement

## Scope
Refine only the existing landing hero. Keep its copy, search, actions, background artwork, event content, theme behavior, and navigation unchanged.

## Build
- Replace the overly stretched vertical distribution with compact, intentional content groups: message, actions, and social proof.
- Use a centered, structured event-discovery composition that fits Outrazo’s Forest Tech system in both themes.
- On mobile, tighten the headline/action rhythm and overlap the event cards slightly so the proof cluster feels cohesive without crowding.
- On desktop, use the available width more deliberately by placing the social-proof cards as a balanced lower visual anchor rather than leaving dead space.
- Add only restrained token-based separators or framing where needed for organization; no new colors, copy, functionality, or unrelated section changes.

## Validation
- Inspect at 360×640, 394×852, 430×932, 768×1024, 1280×900, and 1440×900.
- Verify dark and light themes, navigation/menu behavior, search, both CTA buttons, text fit, background visibility, and no horizontal overflow.
